# RUA 011 — Vitrine demonstrativa

Marca fictícia. Catálogo estático de moda masculina, busca, categorias, promoções e consulta de produto. Preços e disponibilidade são demonstrativos.

## Uso
Abra index.html ou sirva a pasta com um servidor HTTP. Para GitHub Pages, envie o conteúdo desta pasta à raiz do repositório e configure a publicação da branch desejada. Os caminhos são relativos e aceitam subpastas.

## WhatsApp
Em config.js, substitua null por uma string com um número autorizado, incluindo DDI e DDD. Enquanto não configurado, os botões exibem o aviso de demonstração.

## Arquivos
index.html, style.css, mobile.css, script.js, config.js, catalog.js e assets/. Nenhum backend, conta, checkout ou integração de estoque.
